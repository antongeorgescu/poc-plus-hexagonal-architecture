========================================================================
 POTENTIAL INQUIRIES PER USER
========================================================================
These are example questions each demo user can type into the "Ask" box on
the dashboard. They are NOT shown as clickable suggestions in the UI — this
file is the reference list. Password for every account is: demo123

Always shown after login (every user, regardless of question):
  - Account Summary  -> AccountSummaryComponent
       loan info / payments / standing, produced by the CLL
       AccountSummaryService, which sums up the deterministic BLL collectors:
       UserProfileService + LoanInfoService + PaymentService.
  - Conversation Insights -> ChatInsightsComponent
       Live Chat + Chatbot summary and a sentiment "tone meter"
       (ChatInsightsService). Shown side-by-side with Account Summary.

Ask-box behavior:
  - The answer appears only after pressing "Ask" (or Enter).
  - Answers stack newest-on-top; asking something already shown scrolls to
    the existing card and flashes it instead of duplicating.

Inquiry routing:
  - "Standard" topics (deterministic) show the same component for all users:
      * next payment      -> NextPaymentComponent
      * loan balance      -> LoanBalanceComponent
      * make a payment    -> MakePaymentComponent (Business Logic Layer)
      * update profile    -> UpdateProfileComponent (Business Logic Layer)
  - "Personalized" topics also add the component set for the user's type:
      * payment hardship  -> JobOpportunitiesComponent (+ per-type set)
      * life event/relief -> InterestReliefComponent   (+ per-type set)
      * general/other     -> GeneralHelpComponent      (+ per-type set)

Per-type personalized set (added to personalized topics):
      * Type 1 -> RewardsComponent + RefinanceOfferComponent
      * Type 2 -> AutopayComponent + BudgetTipsComponent
      * Type 3 -> HardshipAssistanceComponent + DebtCounselingComponent

Answer-layer markers ([BLL] / [CLL]):
  Every question is CLASSIFIED by the CLL — it proposes the topic. The marker
  says which layer BUILDS the answer you then see.
    [BLL]      Deterministic answer. The same component for every borrower; all
               figures and validation come from the BLL (payment / loan / profile).
    [CLL]      Cognitive answer. Grounding, narration and per-type personalization.
               No authoritative figure is produced here.
    [BLL+CLL]  Cognitively routed and personalized, but the OUTCOME is a BLL
               decision — rate-relief eligibility and its money math are decided
               in the deterministic layer; the CLL only phrases the result.
